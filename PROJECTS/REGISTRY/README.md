# PROJECTS — Consumer Registry

Este módulo registra proyectos que consumen activos de INnGeNiUs MIND ARCHIVE.

Cada proyecto tendrá una ficha de alto nivel con:
- project_id y nombre;
- propósito y responsable;
- repositorio externo;
- activos del MIND ARCHIVE utilizados y sus versiones;
- restricciones de seguridad y privacidad;
- estado de integración;
- enlaces a documentación propia.

## Separación

El registro no almacena el código fuente, bases de datos operacionales, credenciales ni información sensible del proyecto consumidor.

INnGeNiUs Electoral IA es un consumidor prioritario. Su lógica electoral, datos, configuración y despliegues permanecen en su propio entorno.
