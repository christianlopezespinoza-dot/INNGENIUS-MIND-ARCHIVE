# EXECUTION

Módulo para scripts, herramientas locales y automatizaciones operativas.

## Alcance
- scripts reutilizables;
- herramientas CLI;
- automatizaciones controladas;
- configuración de ejemplo sin secretos;
- instrucciones de instalación y ejecución.

## Reglas
- separar código ejecutable de prompts y documentación conceptual;
- no incluir credenciales;
- declarar entorno, dependencias, entradas, salidas y efectos secundarios;
- limitar permisos y validar argumentos;
- incluir pruebas reproducibles antes de marcar un componente como VALIDATED.

No se incorpora runtime ni se asume una tecnología de ejecución hasta que exista un requisito concreto.
