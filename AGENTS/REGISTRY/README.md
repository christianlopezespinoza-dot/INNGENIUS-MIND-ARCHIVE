# AGENTS — Registry

El registro enumera perfiles de agentes y enlaza sus contratos, Skills autorizados, herramientas y pruebas.

No se crearán perfiles ficticios para completar un número esperado. Los seis agentes mencionados en el historial se incorporarán cuando sus nombres, responsabilidades y límites originales se hayan recuperado y contrastado.

Un registro vacío o incompleto es preferible a inventar identidades o permisos.
